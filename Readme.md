# Ds Web Landing Page

This project is a landing page for the company Ds Web, with the objective of promoting the company's services.

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You need to have Node.js and npm (or yarn/pnpm) installed on your machine.

- [Node.js](https://nodejs.org/) (which includes npm)

### Installation

1.  Clone the repository:

    ```bash
    git clone https://github.com/silvadouglasFull/dswebWeb.git
    ```

2.  Navigate to the project directory:

    ```bash
    cd dswebWeb
    ```

3.  Install the dependencies:
    ```bash
    npm install
    ```

## Running the Project

### Development Mode

To run the application in development mode, execute the following command. This will start the Vite development server, usually on `http://localhost:5173`.

```bash
npm run dev
```

### Production Build

To create a production build of the application, run the following command. The optimized static files will be generated in the `dist` directory.

```bash
npm run build
```
